# D2: `sys_listen` is made by the program; the constructor sets SIGPIPE

Status: **decided**

`sys_listen` is made by the program (straight-line, restricted). The constructor **checks** that fds 0–2 are open, and sets SIGPIPE to ignored

<!-- split from design/36 §9 (spike/echo-live-pol @e179dae84), 2026-10-17 -->

**Superseded in part by [D33](D33.md):** the constructor no longer checks fds 0–2 (it keeps SIGPIPE); the program checks them itself with `sys_fdok` and stops with outcome `stdio_closed` if one is closed.
