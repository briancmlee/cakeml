# D33: Stdio checked by the program

Status: **approved (user, via coordinator)**

**Stdio checked by the program** (design/50 (c2), option (ii): a per-fd query). A query-only call `sys_fdok` (conf: the fd, 1 byte; a 1-byte result, no header): 1 if the fd is open and 0 if not. The model answers `MEM (w2w fd) (l0_used w)`, exactly; the world is unchanged. The C is just `fcntl(fd, F_GETFD) >= 0` ([P fcntl]: EBADF iff the fd is not open). The C constructor no longer checks 0–2 (it keeps SIGPIPE). Programs always call it on 0, 1 and 2 first (no early exit), then stop if any is closed: a new claim outcome `honestL0Outcome.stdio_closed` (the three events, some answer 0). The world assumptions drop `MEM 0w/1w/2w reserved` (l0_server_world; l0sys sys_init and l0_fresh drop `MEM 0w`). *Revised (user):* replaces the first approved form, one 3-byte `sys_stdio` call
