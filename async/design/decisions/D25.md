# D25: Handle-room guard counts only Accept actions

Status: **decided (user, via coordinator)**

**Handle-room guard counts only Accept actions** (echo liveness cut-off). Handles are the 2^64 − 1 word64 values other than lfd's (`l1hdln` skips it), and `l1hdln lfdn j < 2^64 ⇔ j + 1 < 2^64` (`l1hdln_lt`). Only an Accept action takes one (and only when a prefetched connection is waiting: an unhanded prefetched accept takes none). The round's guard was `l1hdln (nxt + LENGTH acts) < 2^64`, counting every action and stricter by one; it is now `nxt + naccepts acts < 2^64` (`pl2_ok`, `pround_ok`): exactly what the round's accepts can need, so a server issuing one Accept a round is served while fewer than 2^64 − 1 connections have been handed out. Statements: only the room hypothesis of R1-live (`pl2_ok`) changes, and it gets weaker; R1-safe's own hypotheses are unchanged
