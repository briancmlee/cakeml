# L3-02: facts about the L0 world

- `honestL0WorldProps`: buffer lengths, the choices and the rely are kept
  by time and calls, and result lengths (17 theorems).
- `honestL0WorldInv`: the world invariant `l0wf`, `noconn` and the
  pending-connection lemmas, along a run (42 theorems).

These are proved facts, with no trust. They are used by L1's wrapper proofs
(L3-03 on).
