# D28: Silent input loss is an excuse

Status: **decided (user, via coordinator)**

**Silent input loss is an excuse** (async-spike's finding #4). Input the kernel discards on a broken channel (D21's eof_first path, or a transient break error followed by `Ok 0`) is never read, so never echoed. `echo_live_l0`'s excuses gain `flushed_ch w0 io c` (channel c broke with its unread input discarded). Corollary `echo_live_l0_noflush` (proved in L3-00): with no flushed channel in the run, only the observed excuses (`ep_hard_err`, `ep_timed_out`) remain; the hypothesis is a world-level fact, not observable on the trace.
